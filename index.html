Misiones completadas

Misión A

Interrupciones INT 00H en TASM

Implementación de servicios BIOS/DOS con la interrupción INT 00H y rutinas vecinas en Turbo Assembler. El objetivo fue entender el puente entre hardware, vector de interrupciones y software de usuario: cómo un programa cede el control a la CPU, captura flags y restaura el contexto.

Misión B

IoT en Cisco Packet Tracer

Diseño de una arquitectura de red con sensores, gateway, switch, firewall y servidor de aplicación. Se modeló el flujo MQTT/HTTP, VLANs y políticas de acceso para que los dispositivos IoT dialoguen sin exponer la LAN académica.

Misión C

Diagramas UML

Elaboración de casos de uso, clases, secuencia y componentes para documentar decisiones estructurales. El UML se usó como mapa del mundo: no como adorno, sino como contrato visual entre analistas y constructores.
